# باینری‌های همراه cwebp / avifenc (اختیاری)

این پوشه خالی است. افزونه بدون این باینری‌ها هم کامل کار می‌کند (با GD)؛
قرار دادن فایل‌های زیر فقط فشرده‌سازی را کمی بهتر می‌کند (معمولاً ۵ تا ۱۵٪ حجم کمتر).

## چطور فعال کنم؟

۱. باینری رسمی و **از پیش کامپایل‌شده (precompiled release)** را مستقیماً از صفحه Release
   پروژه‌ها دانلود کنید - نه از سورس‌کد:
   - cwebp: https://github.com/webmproject/libwebp (بسته‌های release شامل `cwebp` هستند)
   - avifenc: https://github.com/AOMediaCodec/libavif (بسته‌های release شامل `avifenc` هستند)

   نسخه‌ای را انتخاب کنید که با معماری/سیستم‌عامل هاست شما یکی باشد. اکثر هاست‌های
   اشتراکی/VPS وردپرس، **Linux x86_64** هستند. اگر مطمئن نیستید، از طریق SSH روی
   سرورتان دستور `uname -sm` را اجرا کنید.

   نکته مهم: برای بیشترین سازگاری بین توزیع‌های مختلف لینوکس (Ubuntu/CentOS/Alpine و...)
   ترجیحاً نسخه **static/statically-linked** را انتخاب کنید (وابستگی به کتابخانه‌های
   سیستمی ندارد). نسخه‌های عادی هم معمولاً کار می‌کنند اما ممکن است روی برخی هاست‌ها
   به دلیل نبود glibc/musl سازگار اجرا نشوند - در این حالت افزونه بی‌صدا به GD برمی‌گردد.

۲. فایل باینری را (بدون تغییر نام پوشه‌بندی، دقیقاً با همین نام) اینجا کپی کنید:

   ```
   assets/bin/linux-x86_64/cwebp
   assets/bin/linux-x86_64/avifenc
   assets/bin/linux-aarch64/cwebp      (فقط اگر هاست شما ARM64 است)
   assets/bin/linux-aarch64/avifenc    (فقط اگر هاست شما ARM64 است)
   ```

   نام فایل باید دقیقاً `cwebp` و `avifenc` باشد (بدون پسوند)، داخل پوشه معماری درست.

۳. نیازی به chmod دستی نیست - افزونه در هر اجرا خودش `chmod 755` روی این فایل‌ها
   می‌زند (چون آپلود Zip/FTP معمولاً بیت اجرایی را حذف می‌کند).

۴. برای بررسی این‌که فعال شده، به **OptiSnap → 🏥 داشبورد و مدیریت** بروید؛ اگر
   باینری معتبر پیدا شود، وضعیت «✅ فعال» را همراه با برچسب «همراه افزونه» نشان می‌دهد.

## نکات مهم

- اگر میزبان شما (Hosting) اجرای `exec()`/`shell_exec()` را غیرفعال کرده باشد
  (رایج در برخی هاست‌های اشتراکی مدیریت‌شده)، این باینری‌ها اصلاً اجرا نمی‌شوند و
  افزونه به‌طور خودکار و بی‌صدا از GD استفاده می‌کند - هیچ خطایی به کاربر نمایش
  داده نمی‌شود.
- اگر روی سرور شما نسخه‌ای از `cwebp`/`avifenc` از قبل نصب است (مثلاً با
  `apt install webp libavif-bin`)، همان نسخه سیستم اولویت پایین‌تری نسبت به این
  پوشه دارد؛ یعنی اگر فایلی اینجا بگذارید، همین فایل استفاده می‌شود، نه نسخه سیستم.
- این افزونه هیچ باینری‌ای را خودش دانلود یا اجرا نمی‌کند مگر همان چیزی که شما
  دستی در این پوشه قرار داده باشید.
